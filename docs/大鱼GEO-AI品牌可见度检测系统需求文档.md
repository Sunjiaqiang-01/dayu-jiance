## 一、产品定位

### 1.1 产品定位

**大鱼GEO** 是大鱼GEO销售团队的**AI品牌机会发现引擎**，帮助销售人员在客户拜访时快速发现品牌在AI时代的机会和威胁，现场出具专业报告，展示大鱼GEO的专业能力。

### 1.2 核心价值主张

| 旧定位 | 新定位 |
|--------|--------|
| 检测品牌在AI中的可见度分数 | 发现品牌在AI时代的机会和威胁 |
| 展示问题 | 发现机会 |
| 给建议 | 告诉先做什么 |

## 四、核心检测逻辑

### 4.1 设计理念：从"检测工具"到"机会发现引擎"

**旧定位**：检测品牌在AI中的可见度分数
**新定位**：发现品牌在AI时代的机会和威胁

```
┌─────────────────────────────────────────────────────────────────────┐
│              核心升级：检测 → 发现                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  检测：品牌现在是什么状态                                  │   │
│  │  发现：品牌应该是什么状态                                  │   │
│  │  差距：机会在哪里                                          │   │
│  │  行动：先做什么                                            │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.2 四步闭环检测流程

```
┌─────────────────────────────────────────────────────────────────────┐
│              检测流程：四步闭环                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  【Step 1：场景覆盖检测】  ⏱️ 15秒                        │   │
│  │  目标：发现用户在问哪些问题，品牌出现在哪些场景中           │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              ↓                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  【Step 2：竞品格局发现】  ⏱️ 15秒                        │   │
│  │  目标：从AI行业认知中，发现真正的竞争对手是谁               │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              ↓                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  【Step 3：机会差距分析】  ⏱️ 10秒                        │   │
│  │  目标：量化"现状"与"应该"的差距 = 机会清单               │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              ↓                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  【Step 4：行动优先级排序】  ⏱️ 5秒                       │   │
│  │  目标：按"收益/成本"排序，告诉销售先做什么                │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.3 Step 1：场景覆盖检测

向AI提问发现高频场景，然后检测品牌在各场景中的覆盖情况。

### 4.4 Step 2：竞品格局发现

不带品牌名提问，获取客观的AI行业认知。

### 4.5 Step 3：机会差距分析

**核心公式**：机会 = 高频场景 × (品牌缺失或弱势)

### 4.6 Step 4：行动优先级排序

按"收益/成本"排序，输出TOP 3优先行动。

## 六、兜底策略

### 6.1 各步骤兜底机制

| 步骤 | 失败场景 | 兜底策略 |
|------|----------|----------|
| Step 1 | 无法获取高频场景 | 使用预设行业TOP10场景 |
| Step 2 | 无法提取竞品 | 使用预设行业TOP10品牌 |
| Step 3 | 机会计算失败 | 转为展示覆盖矩阵 |
| Step 4 | 行动排序失败 | 按场景重要性排序 |

### 6.2 平台级兜底

| 场景 | 处理策略 |
|------|----------|
| 单平台API失败 | 显示已成功平台，不影响整体 |
| 多平台API失败 | 使用成功平台数据，标注"部分数据" |
| 所有平台失败 | 返回友好提示，可重试 |

| AI平台API不稳定 | 高 | 中 | 多平台备份，失败不影响整体 |
| 场景发现不准确 | 中 | 中 | 预设场景兜底 |
| 竞品提取失败 | 中 | 中 | 预设行业TOP品牌兜底 |
| 报告样式客户不满意 | 中 | 高 | 提供模板自定义能力 |
| 检测速度太慢 | 低 | 高 | 并发优化，目标<60秒 |
| 销售不用工具 | 中 | 高 | 纳入销售培训，上线前宣导 |

### 13.2 数据库设计（初稿）

```sql
-- 检测记录表
CREATE TABLE detection_records (
    id VARCHAR(36) PRIMARY KEY,           -- UUID
    brand_name VARCHAR(255) NOT NULL,     -- 品牌名称
    industry VARCHAR(100) NOT NULL,       -- 行业
    status VARCHAR(50) DEFAULT 'pending', -- pending/running/completed/failed
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    completed_at TIMESTAMP,
    
    -- Step 1 结果
    scene_coverage JSON,                  -- 场景覆盖数据
    scene_coverage_score INT,             -- 场景覆盖分数
    
    -- Step 2 结果
    competitors JSON,                     -- 发现的竞品列表
    
    -- Step 3 结果
    opportunities JSON,                   -- 机会列表
    
    -- Step 4 结果
    action_items JSON,                   -- 行动建议
    
    -- 元数据
    total_duration INT,                  -- 总耗时（秒）
    platform_results JSON                 -- 各平台调用结果
);

-- 报告表
CREATE TABLE reports (
    id VARCHAR(36) PRIMARY KEY,
    detection_id VARCHAR(36) REFERENCES detection_records(id),
    file_path VARCHAR(500),              -- PDF文件路径
    generated_at TIMESTAMP DEFAULT NOW(),
    status VARCHAR(50) DEFAULT 'pending' -- pending/generating/completed/failed
);

-- 系统配置表
CREATE TABLE system_config (
    key VARCHAR(100) PRIMARY KEY,
    value TEXT,
    description VARCHAR(255),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 行业场景预设表
CREATE TABLE industry_scenes (
    id VARCHAR(36) PRIMARY KEY,
    industry VARCHAR(100) NOT NULL,
    scene_name VARCHAR(255) NOT NULL,
    scene_description TEXT,
    priority INT DEFAULT 0
);
```
